# G-PROJECT working rules

This GitHub repository currently contains game-design references and auxiliary tools. Do not presume that it contains the Unreal Engine .uproject, its Content directory, or the owner's complete Windows workspace.

- Primary game target: Unreal Engine 5.8. Confirm an actual .uproject path and engine executable before running Unreal or changing game assets.
- Start with a small vertical slice; provide compilation, PIE or automated test results, and real visual evidence for any visual change.
- Preserve unrelated work, original assets, hand-authored Blueprints, animation files, and source references. No mass cleanup or replacement.
- Do not download paid assets, commit licensed game rips, silently expand feature scope, or push changes without explicit direction.
- Use one isolated feature branch for AI-assisted implementation. Never merge into main automatically.
- Claude Code's user-invoked /ship skill coordinates gp-planner, gp-coder, gp-tester, and gp-reviewer.
- A reviewer verdict is a recommendation only; owner acceptance is required for visual milestones and merging.
- For current combat priorities, read Design/Combat/ASTRA_START_HERE.md before changing combat behavior.
